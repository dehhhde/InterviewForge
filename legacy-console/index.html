检测连接中
这个页面是用 file:// 直接打开的本地文件。 浏览器会拦掉跨域响应，所以即使服务正常处理了请求，页面也只会报"不可达 / 失败"—— 而上传已经真的写进了库，看到"上传失败"再点一次，库里就多出一份简历。 请改用 http://127.0.0.1:8000/ 打开控制台 （页面与 API 同源，不需要 CORS，也不用动右上角的 API 根地址）。
